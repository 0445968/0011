# Bundled font assets

These fonts retain the existing Careers and demo typography while removing Google Fonts network fetches during builds. Font-family CSS variables and requested weights are unchanged. OFL licenses are included beside the fonts.

- Caveat, DM Sans, Space Grotesk and Cormorant Garamond variable fonts, losslessly compressed to WOFF2 from upstream TTF files: https://github.com/google/fonts/tree/main/ofl (retrieved 2026-10-30).
- IBM Plex Mono Latin normal WOFF2 files: existing @fontsource/ibm-plex-mono dependency; its license is included.
